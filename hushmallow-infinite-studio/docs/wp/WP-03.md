## What was built

### Composer (`composer/`, pure ESM, no wall clock, no unseeded randomness)

| Module | Job |
|---|---|
| `compose.js` | `compose(spec, { lib, data?, measure?, moves? })` is the planner's seam (async). It loads the Node inputs on demand. `composeWith` is the pure synchronous core. Its steps: moves in slot order → personality → acting/bridges → build → circular wrap. It records provenance: cells and versions, the pack/preset/matrix sha256, prop authorship and bridges. |
| `clock.js` | Anchors from the library beat clock and `at()` (1 µs grid snapping). `resolveRef('TURN-0.05')`. `breathPeriod(D) = D / round(D / 3.8)`. Seeded anchor jitter (±80 ms) that never moves frame-locked anchors and never reorders anchors. |
| `channels.js` | The channel catalogue, `ChannelSet` and `checkChannels`. `ChannelSet` handles ownership windows, keys merged and **sorted before the Track is built**, and merge rules (owned, sum, max). `checkChannels` reports structure errors on a finished direction. Also: the typed evaluators (track, spline, impulses, hops, blinks, shimmer, ripples, noise, sine, envscale, ramp, pulse, const, expr), with v2's operand order kept. |
| `scene.js` | `createScene(direction)` is **the one evaluator of direction semantics**: state, sub-frames and motion. The runtime, G-DIR, G-COST and the dry runs all share it. |
| `moves/**` | The ten v2 moves (below) plus `acting/bridge.js`. `index.js` is the registry, with constant imports, slot order and `moveOf` (which accepts an injected registry for tests). |
| `personality.js` | Personality (amplitude, tempo, lag) and intents expanded through the app's `PRESETS` by an adapter. Also the app's eye gate for closed-eye Mallows. Noomi is the reference performer. |
| `acting.js` | The deferred-value resolver (`R.A`, `R.post(s)`, `R.propAt`, `R.lookAt`), seeded auto-blinks, micro-noise, and **`breathEnvelope(direction)`, the single exported breath envelope** (R11, picture side). |
| `poses.js` | The pose table (asleep, startled, alert, spiralling, squeezed, calm, content), compatibility, and `planBridges`. A mismatch with no room for a bridge is the compile error `pose:no-room`, never a pop. |
| `layout.js` | Text styles, `wrap2`, hook auto-fit (76 → 50 px), glass-card boxes (v2's `bubbleCanvas` maths) and the TextBlock/LogoCard visibility models. `measure()` is injected: canvas in the page, the Fredoka metrics shim in Node. |
| `circular.js` | `wrapTime` (t ≥ D−P → t−D; P = 0 is the identity, not even a subtraction), `domain`, `closure`. |
| `palette.js`, `controllers/orbit.js`, `audio.js` | Palette triples blended by the world dials, v2's orbit controller for the thought cards, and the shared pan constants. |
| `validate.js` | G-DIR: structure, loop closure, deformation at 240 Hz, camera, text, safety, craft, audio linkage and poses. Calibrated thresholds are listed under "Deviations". |
| `cost.js` | G-COST. Three models: exact (fitted to WP-01's measured render), final and draft (both provisional until WP-02 refits them). |
| `artefacts.js` | Review artefacts from a dry evaluation (R12): `dryRun(direction)` gives the cue log, curves and sub-frame counts in the engine's shape; `channelPlotSvg(direction)` gives channel plots. |
| `lib-node.mjs`, `library.js`, `versions.mjs` | Node inputs: library files, the face spec through `engine/face.js`, the recorded silhouette checked against the art's sha256, and the metrics shim. Also a Node-free story-library index and the move versions for the tuning matrix. |
| `schemas/*.json` | Schemas for the direction v3, move, mallow pack, realm preset and tuning matrix. They use only the keywords `planner/spec-schema.mjs` implements. |

### Runtime v3 (`engine/runtime/direction-runtime.js`, the only engine file WP-03 adds)

- `createDirectionRuntime({ direction } | { spec })` exposes `{ contract: 'v3', meta, setup, state, overlay, subframes, probes, dispose }`, so `engine/stage.js` needs no change. It has no module-level state (R4).
- **`{ spec }` input:** the runtime composes in the page at setup (`composeInPage`). It fetches the pack, preset and matrix and records their sha256 (`crypto.subtle`), derives the face spec, re-measures the silhouette, and lays out text with the loaded font.
- **`{ direction }` input:** the runtime renders a compiled direction. It first re-checks the silhouette and the face spec against the assets, and refuses three kinds of direction:
  - shim-laid-out directions (unless `allowShimLayout`);
  - malformed channels;
  - other schemas.
- `engine/stage.js` is imported lazily, so the module also loads in Node (unit-tested).

## Deviations from the plan, with reasons

1. **The bit-exact gate runs in the page, not in Node.** Node's V8 `Math.pow` differs from Chromium's in the last bit. Measured with v2's own palette code: Node gives 0.002932318323938363, Chromium 0.0029323183239383624. The Node composer still agrees within about 1.9e-12, and its sub-frame counts and cues are exact. The plan expected a Node dry run to be the reference; the reference curves for the score come from the page's `dryRun()`, as the plan's R12 fix requires.
2. **G-DIR thresholds calibrated on the approved v2.** Five plan values would reject the approved video itself. Each changed one is marked provisional in `THRESHOLDS` and pinned by a test ("thresholds that differ from the plan are the calibrated ones"); the owner or WP-13 should confirm them:
   - **Stretch:** the plan says ≤ 1.3. v2 reaches **1.386**, so the limit comes from the pack (`limits.stretchMax 1.4`, Noomi).
   - **R-BREATH exhale:** the plan says ≥ 1.5× inhale. v2 has **1.28×** (inhale 1.48 s, exhale 1.9 s), so the limit is 1.25×.
   - **Rest windows at the seam:** "≥ 0.25 s on each side" is kept for "any rest" (v2: 0.249 s, with a 2 ms sampling tolerance). "Fully at rest" after the seam is 0.15 s (v2: **0.171 s**).
   - **Caption reading time:** an error is raised on the visible window. "Fully clear at alpha ≥ 0.9" is only a warning: v2's end card is clear for **1.95 s** of the 2.35 s its length asks.
   - **Right rail and glass cards:** v2's second thought card crosses the rail for **0.72 s** while readable, so this is a warning. Glass readability uses card alpha ≥ 0.75, because depth dims the back cards to 0.84. The 0.9 rule is kept for captions.
3. **Registry wiring and the farm job key are left to the integrator.** `engine/directions.js`, `render/farm.mjs` and `render/lib/provenance.mjs` are not WP-03's files. The patches are ready and validated (see "Open issues").
