## F3 · GLOBAL — hide game selection; ThinkStill always picks the next best release, no repeats until the group is finished — OPEN · founder decision 2026-10-09 (supersedes Part 9's manual selector)
- **Founder:** "instead of user having to select the type of release, I really want to hide all the options from the user and let ThinkStill have a logic with which it works out the next best. But remember no release should repeat until all groups of releases finish."
- **Required:**
  1. **No game selection UI for users:** hide the CHOOSE TO RELEASE dropdown / game list / "pick myself" paths. Keep the code (never delete features) behind a Framer property control `Show game menu` (default OFF, owner/testing only) and a dev hook so automated tests can still start any game by id (dev/drive.mjs + dev/eos_drive.mjs must keep working: add a `?menu=1` / window.__eos test hook if the menu is hidden).
  2. **ThinkStill picks the next best game automatically** from what the user entered (emotion detected from words / check-in emotion + intensity, time of day, safety flags) using the existing router (src/eos/45_eos_router.jsx EosRouteGame / EOS_EMOTION_ROUTES) — best-fit first.
  3. **No repeats until the group is finished:** a persistent no-repeat rotation (localStorage, never user text): within the emotion's group, never serve a game again until every game in that group has been played once; then start a new cycle (never the same game twice in a row across a cycle boundary). Also never serve a game played in the last few sessions even when switching emotions, unless the group is exhausted. Only playable games (no broken/stalled ones) enter the rotation.
  4. **After a game:** the end screen's "Next" / "Try next game" button plays the next game from the rotation (no picker); "Again" replays the same game on the user's request; "New thought" returns to input.
  5. **Safety flags still override** (gentle list), and the rotation respects them.
  6. **Founder reiterated (2026-10-09): "don't show any options to select games — just let ThinkStill decide for them."** So remove EVERY user-facing way to choose or browse games: the CHOOSE TO RELEASE menu, game lists/cards, "pick myself"/"choose a game" links in the check-in, named "Try <GAME>" suggestion buttons, PREVIOUS/NEXT game browsing arrows that let users step through the catalogue, and any game names presented as choices. What remains: ThinkStill starts the chosen game automatically; at the end one **Next** (ThinkStill's next pick from the rotation), **Again** (replay this game) and **New thought**. Mid-game "skip" may exist only as "Next" (ThinkStill decides). The owner-only Framer property and the test hook keep the hidden menu available for the owner and automated tests.
- **Test:** unit test in the harness: for each emotion, simulate N = group size + 3 sessions — no repeats until all group games were served, no back-to-back repeat at the cycle boundary, persistence across reloads; UI test at 390x844 and 1280x860: no game picker visible anywhere; Next serves the rotation; the property control re-enables the menu for the owner.
