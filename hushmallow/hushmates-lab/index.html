    What’s real and what’s simulated
    • Real: the relay’s rules (five distinct people, never the author, one each, atomic expiring holds, no repeat exposure, idempotent writes, rate limits, the opt-in Mallow fallback with one generation per feeling, budgets, reports) run in the service and are covered by automated tests, including forged requests.
    • Real: each phone reaches the service only through a network layer with latency, offline mode and lost replies.
    • Simulated: the service runs inside this page and saves to this browser. Sign-in is simulated for seven labelled test identities. No Supabase, no server, no real people. Every perspective is typed by the person operating the lab.
    • Not live AI: no AI key is configured. Mallow perspectives come from a labelled canned example, the Reframe library, or a local Another Angle server in mock mode, and are labelled as such.
