# ThinkStill Release Console: Pixar / Viral / Hypnotic layer

## Install (Framer) — two code files
1. **ThinkStillReleaseConsoleBase.tsx**: paste your ORIGINAL full Release Arcade component here, unchanged.
2. **ThinkStillReleaseConsole1.tsx**: paste the upgrade wrapper (`ThinkStillReleaseConsole1.tsx` / `.txt`) here.
3. Put **ThinkStillReleaseConsole1** on the canvas. All the original property controls carry over, plus
   Pixar Juice, Combo Pops and Pixar Intensity.

The two files must have different names. If the wrapper loads itself you get
"Cannot read properties of undefined (reading 'propertyControls')".
