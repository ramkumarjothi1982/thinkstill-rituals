# ThinkStill Ritual JSON Export

This folder contains JSON exports created from `ThinkStill_FINAL_10K.xlsx`.

Files:
- thinkstill_DROP_v10.json
- thinkstill_GLITCH_v10.json
- thinkstill_LOOPIE_v10.json
- thinkstill_PATCH_v10.json
- thinkstill_RUSH_v10.json
- thinkstill_STILL_v10.json
- thinkstill_SYNC_v10.json
- thinkstill_ALL_v10.json
- thinkstill_rituals_manifest_v10.json

Each bubble file is a JSON array of ritual objects.
The manifest includes counts, filenames, and SHA-256 hashes.
