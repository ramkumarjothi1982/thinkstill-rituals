# ThinkStill v19.5 Deployment

1. Keep all files in this release folder together.
2. Upload each stable JSON file and its matching `.v19.5.json` file.
3. Upload `thinkstill-manifest.json`.
4. Use `ThinkStillUnifiedChat_v38.51.0_FINAL_RELEASE_14ROW_LANGUAGE_PATCH.txt` in Framer.
5. The Framer component contains the same 750 v19.5 ritual surfaces as an embedded fallback.
6. Run `npm run validate:thinkstill` and `npm run test:routing` before deployment.

Do not mix v19.4 and v19.5 data files.
