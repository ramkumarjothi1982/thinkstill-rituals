# Security

## Reporting

Do not publish sensitive user data in a GitHub issue. Report product security concerns privately to the repository owner.

## Data handling

The included static app:

- has no account system
- has no analytics
- sends no typed moment text to a server
- stores no-repeat state and progress only in browser local storage

## Access control

GitHub Pages is public hosting. A hidden URL, redirect or Circle-only button does not create authentication. Use authenticated hosting or an access proxy when membership gating is required.
