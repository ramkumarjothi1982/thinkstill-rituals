## GitHub upload

Upload every file in this folder directly into:

```text
ramkumarjothi1982/thinkstill-rituals
```

Do not create any subfolders.

The raw manifest URL remains:

```text
https://raw.githubusercontent.com/ramkumarjothi1982/thinkstill-rituals/refs/heads/main/manifest.json
```

The Bubble URLs will be:

```text
https://raw.githubusercontent.com/ramkumarjothi1982/thinkstill-rituals/refs/heads/main/rituals_glitch.json
https://raw.githubusercontent.com/ramkumarjothi1982/thinkstill-rituals/refs/heads/main/rituals_drop.json
https://raw.githubusercontent.com/ramkumarjothi1982/thinkstill-rituals/refs/heads/main/rituals_still.json
https://raw.githubusercontent.com/ramkumarjothi1982/thinkstill-rituals/refs/heads/main/rituals_patch.json
```
