THINKSTILL — GITHUB UPLOAD

OPTION 1: GitHub website
1. Sign in to github.com.
2. Select New repository.
3. Name it thinkstill-ritual-chatbot.
4. Create the empty repository without adding a README, .gitignore or licence.
5. Select “uploading an existing file”.
6. Open this project folder and upload its contents.
7. Commit the upload.

GitHub’s website can struggle with a large folder upload. If that happens, use
GitHub Desktop and add this entire folder as a local repository.

DO NOT UPLOAD THESE GENERATED FOLDERS
- node_modules
- .next
- dist
- .sites-runtime
- .wrangler

They are already excluded by .gitignore.

LOCAL START
1. Install Node.js 22.13 or newer.
2. Open a terminal in this folder.
3. Run: npm ci
4. Run: npm run validate:data
5. Run: npm run dev

PRODUCTION CHECK
Run: npm test

This validates all 750 rituals, builds the production app and runs the automated
tests before release.
