# ThinkStill Bubble Expressions

Corrected standalone expressions package.

Included:
- bubble-expressions/
- expressions_manifest.json
- thinkstill_750_expression_map.json
- README.md

Each of the 7 characters includes 100 separately cropped circular WebP assets (700 total), 512x512, transparent outside the circle.

Characters:
- Glitch
- Drop
- Loopie
- Patch
- Rush
- Sync
- Still

The legacy routing file remains included for compatibility with the original E01-E64 mapping.
