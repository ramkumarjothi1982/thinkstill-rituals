# ThinkStill v37.9 — FULL Ritual Presenter

This package contains all 400 rituals and renders the complete consumer ritual every time.

Visible order:

1. TITLE
2. GOAL
3. RITUAL — all numbered steps
4. WIN
5. Five support lines
6. FORMULA FLOW
7. SAFETY → PAUSE

## Important
Upload ALL files in this folder to the same GitHub repository directory. Do not upload only `index.html`.

Required presentation files:
- `index.html`
- `styles.css`
- `app.js`
- `rituals.json`

The bubble JSON files and manifest are also included for integrations.

The UI intentionally uses normal page flow with no fixed ritual height, no collapsed sections, and no hidden ritual body. The whole ritual is visible by scrolling.
