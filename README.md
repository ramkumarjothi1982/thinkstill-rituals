# ThinkStill v38.4.3 — GAME QUEST UI

This package keeps the locked 400-ritual data unchanged and upgrades the presentation/interaction layer.

## New engagement flow
- Reset Quest / Reset Run game-like HUD
- Mission strip showing the user's signal
- Round counter
- Full ritual remains unchanged: Goal → numbered steps → Win → Tips → Formula Flow → Safety
- Follow-up panel asks: **Did this ritual shift anything?**
- Responses: **Yes, that helped / A little — refine it / Not yet — switch angle**
- If the ritual misses, users can specify what remains strongest: Thoughts looping / Body activated / Urge still strong / Emotion still heavy / Need action
- The next unused ritual is routed using the original issue plus the follow-up cue
- No-repeat pool remains intact
- After 3 rounds the UI suggests rewording the issue or taking a break rather than encouraging endless retries
